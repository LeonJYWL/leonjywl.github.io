# Leon · Built from curiosity.

解压 Leon-prototype.zip，保持目录结构，用浏览器打开 index.html。字体、样式、地平线与项目预览均随包提供。首屏三个导航及 Explore 按钮定位到对应板块。Projects 中可切换两件作品，再点击「进入项目」。研究 PDF、Excel 和项目详情链接使用 u16l.com 上的原路径，需要联网。

首页采用静态 HTML、CSS 和仅用于切换预览的 JavaScript。浏览器禁用 JavaScript 时，正文、导航、附件和两件作品链接仍然可用。

## 设计与维护

- Hero 按照参考图的横向比例、页首分隔线、标题位置及地平线高度制作。使用本地 Allura 签名字体与 Libre Caslon Display 标题字体，两份原始字体许可证均在 assets 中。地平线为单独生成的无文字 WebP。
- Research 以报告书封与窄栏摘要并置，分开呈现完整报告和原始数据。未来新增研究时可沿用 article 结构，保持每项报告与附件的对应关系。
- Projects 是单一展台。两张静态预览来自仓库中的鹈鹕动画及互动邀请函。切换时同步更新图片、说明及目标链接。将来可以同样的方式放入模型预览图、工具或游戏链接。新增项目时更新 projects.js 数据及 HTML 选择按钮。
- About 采用简短自述和落款。暖灰纸色承接首屏的暖色高光，保留以后扩写个人介绍的空间。
- 首次实际渲染后，加宽桌面标题，调整高光及地表纹理，并让手机使用宽幅地平线的局部取景。正常滚动使用浏览器原生锚点。减少动态效果模式下立即定位，按钮悬停不产生过渡。

## 截图与验证

screens 中包含桌面四段截图及纵向全页图，另有手机首屏和完整长图。截图视口为 1440×810 和 390×844。Chromium 在 320、390、768、1024、1440px 宽度下核验页面无横向溢出，测试导航、Explore、回到顶部、键盘切换项目、预览图加载和脚本错误。正式域名被当前网络代理拒绝访问（403），四个链接已核对远端 main 的对应文件。真实 iOS、Android 与读屏软件尚未实测。
