## 从三个样本长成一个个人世界

漂流台可按主题编组当季的三股洋流，完整档案另行按时间与媒介检索。接枝簿可让每篇条目带一则有具体理由的关联手记，跨领域阅读靠编辑选择建立。折页印刷所可将同一时期的研究、游戏与 3D 习作编成一期，旧期留在印件目录。三套阅读室都把正文放在独立的浅色窄栏；正式整合时，为每个条目配置持久 URL 与返回档案的路径。

目前实现为三条固定样本。未来的内容条目可共享标题、摘要、媒介、主题、日期和资源链接；洋流归组、关联条目和期号分别属于各自方案。下一阶段扩展目录与分页时再接入真实内容。房企报告与鹈鹕实验沿用正式站资源，程序图形为本次原型创作。

## 研究、自评与修改

调用仓库级 ui-ux-pro-max，定向检索 organic biomimicry、spatial navigation 与 kinetic typography，分别得到 Organic Biophilic、Dimensional Layering 与 Kinetic Typography。三套原型自主绘制，没有导入上一轮的 SVG。外部创意网站在当前云端未能打开，未将它们作为已审阅案例。

首稿已在 Chromium 渲染。缩小对照后，三种轮廓可辨，但操作几乎都是按按钮换条目。第二稿为漂流台增加直接改变几何的水流控制；接枝簿增加逐条撰写的关联理由和并读入口；印刷所增加可用键盘展开的折角控制。保留普通文字目录，访客可以直接打开作品。画布只在初次绘制、窗口变化与操作时重绘；切换动效在 540ms 内结束，减少动态效果模式下直接呈现终态。

在 Chromium 的 320、390、768、1440px 宽度下检查页面溢出、切换后标题、阅读室打开与 Esc 关闭及脚本错误。另验证滑杆键盘操作改变画布像素，关联入口打开正确条目。全页截图视口为桌面 1440×940、手机 390×844。真实手机 GPU 与读屏软件尚未实测。

**推荐接枝簿。** 三套中，它最能把长期积累变成访客能感受到的关系。财务研究与 AI 实验之间已有一条具体的「原材料」连接；以后加入三维作品，也可以沿构图、光线或生成规则接入。其维护成本是每次发布都需要写好关联理由。漂流观察站最适合希望首次访问就记住电光蓝形象的方向；折页印刷所更适合周期性发布作品集。
