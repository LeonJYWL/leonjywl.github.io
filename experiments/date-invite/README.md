# Date Invitation V1.0

一封可以反复使用的五幕静态邀请。审核合并到 `main`、GitHub Pages 完成发布后，可使用下列地址。

| 用途 | 地址 |
| --- | --- |
| 通用邀请 | https://leonjywl.github.io/experiments/date-invite/ |
| 邀请生成器 | https://leonjywl.github.io/experiments/date-invite/create.html |

## 生成与使用

直接发送通用邀请即可用「你」称呼收件人。制作专属邀请时，在生成器填写昵称，点击「生成邀请链接」，预览后复制完整链接到微信。默认邀请人为 Leon。展开高级设置可修改署名、正文和普通餐饮。使用默认设置并留空昵称即可生成通用链接。

收件人拆信后可以接受或婉拒。接受后依次确认活动、本地日期与具体时间、餐饮。完成后点击「保存图片」，将 PNG 发给邀请人。微信内可长按票根保存，也可截图。活动与餐饮仅表达意向，预订和发送结果均由双方自行处理。

刷新、重新打开和「重新开始」都会清空本轮选择，保留链接配置。页面没有跨幕返回、草稿、登录或后台。

## 链接与数据

- 配置放在 URL 的 `#v1.` 片段中。仅保存与 V1 默认值不同的字段，以 UTF-8 JSON 和 Base64URL 编码。相同程序可同时打开多份独立邀请。
- 编码可逆，任何持有链接的人都能读到配置。请只填写昵称和邀请内容，避免输入手机号、密码或住址。生成器不收集联系方式。活动、日期时间和餐饮答案只在页面内存中使用。
- 昵称各限 24 个 Unicode 码点，正文限 180 个。普通餐饮支持 1–9 项，每项图标最多 12 个码点，名称最多 16 个。生成链接总长最多 3000 个字符。组合 Emoji 可能占多个码点。
- 解码前检查版本、字符和长度，解码后检查字段和保留选项。无法读取时提示并使用通用邀请。显示自定义文字使用文本节点及 Canvas。
- 保留完整片段才能恢复专属设置。分享工具若截断或丢弃整个片段，邀请会回到通用称呼。复制受限时会选中链接，供长按或快捷键复制。

## 本地预览

在 PR 分支的仓库根目录执行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000/experiments/date-invite/> 或同目录的 `create.html`。页面使用原生 ES 模块，请通过 HTTP 预览。生成器沿用当前站点路径，本地预览生成的链接仅用于本地测试。分享正式邀请时请从正式生成器生成。

规则测试使用 Node.js 22.7+ 的内置测试运行器，无需安装包。

```sh
TZ=Asia/Shanghai node --test experiments/date-invite/tests/rules.test.mjs
TZ=America/Los_Angeles node --test experiments/date-invite/tests/rules.test.mjs
```

## 验收记录

在本地 HTTP 服务和 Chromium 154 中实际跑通以下场景。

| 操作 | 已核对的结果 |
| --- | --- |
| 从空白、中文昵称、含 Emoji 和 HTML 字面文本的正文生成链接 | 通用路径正确。两份专属链接独立，系统剪贴板回读与预览地址一致，正文按文字显示。超长昵称有提示。 |
| 触摸拆信，逐次点击「再考虑一下」，另开一轮用 Enter 拒绝 | 前四次移动均在容器内且与接受按钮分行，第五次拒绝成功。键盘可直接拒绝。 |
| 依次尝试空选、惊喜加普通活动、两项再加第三项、取消 | 继续按钮和卡片状态正确，冲突时保留已有选择。 |
| 选昨天、今天已过时间、快捷时间、自选 18:30 | 空日期或空时间不能继续，过去时间被拦截，票根使用设备本地年月日与星期。 |
| 分别选择吃饭和散步，切换普通餐饮及两个保留选项 | 餐饮单选，吃饭时拒绝跳过餐饮，散步时可以跳过；自定义选项仍按稳定标识校验。 |
| 用长中文昵称、Emoji、长餐饮名生成并下载 PNG | 检查了导出图，文字换行，结尾完整。长内容样例为 1140 × 1785 像素，下载字节与展示图片一致。 |
| 分别刷新、重开，再读旧专属链接 | 回到信封并保留原配置，活动、日期和时间为空。进度条仅用于显示。 |
| 使用 320、375、390、430、768、1280 像素宽度检查页面 | 信封、三个选择阶段、票根和展开的生成器均无横向溢出。减少动态效果时可直接拆信。 |
| 在模拟微信 UA 的 Chromium 点击保存 | 完整图片与长按提示可见。此项仅覆盖代码分支。 |
| 从原首页打开资源，检查 Pelican 实验 | 本地首页正常载入；原 PDF 具有有效文件头，Excel 压缩包完整；Pelican 页面与两个原始样本均可读取。 |

**待真机复核**：在 iPhone Safari、微信 iOS / Android 和常用 Android 浏览器中，从微信消息打开完整专属链接，试用原生日期与时间面板、复制、长按图片存入相册和转发。系统字体决定 Emoji 外观。浏览器禁用下载时可长按图片，Canvas 无法使用时可截图文字票根。正式 Pages 地址需要合并部署后验证。

## 维护

| 文件 | 职责 |
| --- | --- |
| `index.html`、`assets/post.svg`、`style.css` | 五幕结构、内嵌原创信封、图标、响应式布局及配色变量 |
| `create.html`、`js/create.js` | 生成器界面、预览与复制 |
| `js/config.js` | 默认昵称、正文、活动、普通与保留餐饮、配置校验和版本编码 |
| `js/choices.js`、`js/invite.js` | 选择规则、本地时间校验、各幕交互与页面内存状态 |
| `js/ticket.js` | 票根布局、可访问文字版、按实测文字宽度换行的 PNG |
| `tests/rules.test.mjs` | 编解码、输入边界、选择规则与日期时间测试 |

单次邀请的文案和餐饮直接在生成器中修改。调整产品默认值时，修改 `js/config.js` 的默认文案与 `FOODS`。保留 `meal`、`surprise`、`host`、`skip` 的语义。旧链接省略了 V1 默认字段，若要更改这些字段同时保留旧邀请的原样展示，应新增编码版本并保留 V1 的解码与默认值。

以后关闭项目时，仅在新分支移除 `experiments/date-invite/` 并提交 PR。首页没有指向本目录的入口，Research Library、Pelican 和 Pages 配置均可独立保留。合并并重新发布后，所有既有邀请链接也会停止服务。
